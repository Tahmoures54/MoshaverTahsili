# چک‌لیست آماده‌سازی و انتشار در کافه‌بازار

این چک‌لیست وضعیت فنی مخزن را از پیش‌نیازهای حساب توسعه‌دهنده و آزمون واقعی جدا می‌کند. تیک‌زدن موارد صرفاً پس از مشاهده مدرک معتبر مجاز است.

## وضعیت فنی مخزن

- [ ] CI آخرین commit روی main سبز باشد.
- [ ] تست‌های واحد و widget بدون خطا اجرا شوند.
- [ ] APK انتشار روی شبیه‌ساز نصب و اجرا شود.
- [ ] APK نهایی با کلید خصوصی انتشار امضا شود؛ امضای Android Debug پذیرفته نیست.
- [ ] نام بسته ir.moshaver.tahsili و نسخه با پنل بازار تطبیق داده شود.
- [ ] SHA-256 فایل تحویلی ثبت شود.
- [ ] APK روی حداقل یک گوشی واقعی و نسخه اندروید پشتیبانی‌شده نصب و اجرا شود.
- [ ] مجوزهای Android با نیاز واقعی برنامه تطبیق داده شوند.
- [ ] صفحه محصول، تصاویر واقعی از نسخه نهایی و سیاست حریم خصوصی آماده باشند.

## Secrets و Variables در GitHub

### Secrets

- AI_API_KEY یا DEEPSEEK_API_KEY
- BAZAAR_RSA_PUBLIC_KEY
- RELEASE_KEYSTORE_BASE64
- RELEASE_KEYSTORE_PASSWORD
- RELEASE_KEY_ALIAS
- RELEASE_KEY_PASSWORD

### Variables

- BAZAAR_CATALOG_CONFIRMED=true فقط پس از تأیید واقعی شناسه محصولات در پنل بازار
- در صورت نیاز AI_API_ENDPOINT و AI_MODEL یا معادل‌های DEEPSEEK_API_ENDPOINT و DEEPSEEK_MODEL

**مهم:** کلید خصوصی/Keystore و رمزهای آن را در مخزن، Issue، پیام عمومی یا فایل‌های artifact قرار ندهید. حداقل یک نسخه پشتیبان رمزگذاری‌شده و آفلاین از Keystore و رمزهایش نگهداری کنید.

## فایل مناسب برای ارسال

در workflow فعلی، APKهای universal و معماری‌محور و نیز AAB ساخته می‌شوند. در آخرین ساخت بررسی‌شده، فایل arm64 حدود ۱۷٫۶۵ MiB و universal حدود ۴۸٫۷۴ MiB بود؛ این اعداد اندازه همان ساخت آزمایشی‌اند، نه اندازه نسخه انتشار امضاشده.

در آخرین ساخت بررسی‌شده، گواهی APK از نوع **Android Debug** بود؛ بنابراین آن artifact برای انتشار تجاری قابل استفاده نیست.

تا زمانی که مسیر امضای بسته AAB و فایل جانبی موردنیاز بازار در پنل/مستندات رسمی تأیید نشده، از APK universal امضاشده با کلید خصوصی انتشار استفاده کنید. AAB تولیدشده را بدون تأیید الزامات بازار بارگذاری نکنید.

## تصمیم انتشار

تا وقتی کلید خصوصی انتشار، تأیید کاتالوگ پرداخت، آزمون خرید واقعی و آزمون گوشی فیزیکی تکمیل نشده‌اند، وضعیت را «نسخه آزمایشی آماده تست» اعلام کنید، نه «منتشرشده» یا «آماده انتشار تجاری».
