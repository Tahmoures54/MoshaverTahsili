# چک‌لیست انتشار سیمرغ برای کافه‌بازار

این چک‌لیست برای مالک محصول و بازبین انسانی است. تیک‌زدن یک مورد فقط با مدرک همان نسخه و همان commit مجاز است.

## ۱. تثبیت منبع و نسخه

- [ ] PR نهایی از `release/prepare-v1` به `main` باز است و هنوز ادغام نشده است.
- [ ] تمام بررسی‌های الزامی GitHub Actions روی آخرین SHA شاخه PR سبز هستند.
- [ ] `pubspec.yaml`، `pubspec.lock` و `.fvmrc` با هم سازگارند.
- [ ] نسخه تأییدشده محصول و شماره ساخت Android در پنل بازار ثبت شده‌اند.
- [ ] هیچ نسخه یا build number بدون تأیید مالک تغییر نکرده است.
- [ ] تغییرات ناخواسته، فایل‌های موقت، کلیدها، رمزها و فایل‌های محلی وارد diff نشده‌اند.

## ۲. کیفیت کد و ساخت

- [ ] `flutter pub get --enforce-lockfile` موفق است.
- [ ] `dart format --output=none --set-exit-if-changed lib test integration_test` بدون تغییر خروجی است.
- [ ] `flutter analyze` بدون خطا و هشدار مسدودکننده است.
- [ ] `flutter test` کامل پاس شده است.
- [ ] `flutter build apk --release` برای معماری مورد انتشار موفق است.
- [ ] گزارش حجم APK و SHA-256 فایل خروجی ذخیره شده است.
- [ ] Android Gradle Wrapper JAR و توزیع Gradle اعتبارسنجی شده‌اند.
- [ ] منابع Manifest شامل آیکون‌ها، Themeها، network security و data extraction در APK resolve شده‌اند.

## ۳. امضای انتشار و حفاظت از کلید

- [ ] keystore موجود و همان کلید نسخه‌های منتشرشده قبلی است.
- [ ] پیش از انتشار، پشتیبان رمزگذاری‌شده کلید موجود تهیه و بازیابی آن آزمایش شده است.
- [ ] چهار Secret امضا به‌صورت کامل و بدون نمایش مقدار در گزارش CI موجودند.
- [ ] متغیر GitHub Actions با نام `EXPECTED_RELEASE_CERT_SHA256` حاوی اثرانگشت SHA-256 گواهی عمومی همان keystore است.
- [ ] اثرانگشت گواهی APK خروجی با اثرانگشت کلید انتشار مورد انتظار تطبیق دارد.
- [ ] APK نهایی با کلید انتشار امضا شده است؛ APK دارای امضای debug فقط برای آزمون است.
- [ ] هیچ keystore، فایل `key.properties`، رمز یا کلید خصوصی در مخزن یا Artifact عمومی قرار نگرفته است.

## ۴. تنظیمات AI و حریم خصوصی

- [ ] دست‌کم یک کلید معتبر AI و endpoint/model مورد تأیید مالک تنظیم شده‌اند.
- [ ] محدودیت مصرف و سقف هزینه برای کلید AI فعال شده است.
- [ ] درک شده است که کلید تعبیه‌شده در APK قابل استخراج است؛ GitHub Secrets آن را از کاربر نهایی مخفی نمی‌کند.
- [ ] متن پرسش و بخشی از سابقه گفت‌وگو که به سرویس بیرونی فرستاده می‌شود در متن حریم خصوصی توضیح داده شده است.
- [ ] ارسال زمینه تحصیلی اختیاری و مبتنی بر رضایت است؛ نام پروفایل نباید به‌صورت خودکار ارسال شود.
- [ ] حذف یا انتقال برنامه، خطر از دست رفتن داده‌های محلی را به‌روشنی اعلام می‌کند.
- [ ] فایل پشتیبان دستی JSON ممکن است حاوی اطلاعات شخصی باشد و باید امن نگهداری شود.

## ۵. کافه‌بازار و خرید

- [ ] شناسه برنامه `ir.moshaver.tahsili` با پنل بازار یکسان است.
- [ ] کلید عمومی RSA رسمی برنامه با پنل بازار تطبیق داده شده است.
- [ ] هر سه SKU، نوع محصول، قیمت و وضعیت فعال‌بودن در پنل واقعی تأیید شده‌اند.
- [ ] `BAZAAR_CATALOG_CONFIRMED=true` فقط پس از تطبیق واقعی کاتالوگ ثبت شده است.
- [ ] خرید موفق، لغو، خرید معلق، خطای شبکه، توکن تکراری و بازیابی خرید روی دستگاه واقعی آزموده شده‌اند.
- [ ] رفتار کیف اعتبار در برابر پاک‌کردن داده، نصب مجدد، بازیابی پشتیبان و دستکاری دستگاه بررسی شده است.
- [ ] محدودیت کیف پول محلی بدون بک‌اند به‌عنوان اعتبار سمت سرور یا موجودی ضد‌دستکاری معرفی نشده است.

## ۶. آزمون روی دستگاه واقعی

- [ ] نصب تازه APK روی Android حداقل پشتیبانی‌شده انجام شده است.
- [ ] ارتقا از نسخه منتشرشده قبلی بدون از دست رفتن داده انجام شده است.
- [ ] ورود اولیه، پروفایل، برنامه‌ریز، ثبت نمره، گزارش، فلش‌کارت و مرور فاصله‌دار آزموده شده‌اند.
- [ ] AI در حالت آنلاین، خطای شبکه، timeout و پاسخ نامعتبر آزموده شده است.
- [ ] ذخیره‌سازی رمزگذاری‌شده، backup/restore و لغو عملیات بررسی شده‌اند.
- [ ] RTL، صفحه کوچک، فونت بزرگ، صفحه‌کلید، دسترس‌پذیری و چرخش صفحه بررسی شده‌اند.
- [ ] مصرف باتری، زمان شروع، پایداری و حجم نصب روی گوشی اقتصادی ارزیابی شده‌اند.

## ۷. آماده‌سازی صفحه محصول

- [ ] نام، توضیح کوتاه و توضیح کامل محصول با قابلیت‌های واقعی نسخه نهایی تطبیق دارند.
- [ ] تصاویر و اسکرین‌شات‌ها از APK نهایی گرفته شده‌اند.
- [ ] سیاست حریم خصوصی، نشانی پشتیبانی و راه ارتباطی معتبر ثبت شده‌اند.
- [ ] کلیدواژه‌ها و ادعاهای تبلیغاتی وعده قبولی، تشخیص استعداد یا نتیجه قطعی نمی‌دهند.
- [ ] قابلیت خرید فقط در صورت فعال و آزموده‌شدن واقعی تبلیغ شده است.

## ۸. تصمیم نهایی

- [ ] مالک محصول گزارش CI، فایل APK، اثرانگشت امضا و نتایج آزمون دستگاه را بررسی کرده است.
- [ ] بازبین انسانی تغییرات PR و محدودیت‌های امنیتی را تأیید کرده است.
- [ ] مجوز ادغام PR به `main` به‌صورت جداگانه صادر شده است.
- [ ] پس از ادغام، اجرای تازه workflow روی SHA ادغام‌شده موفق شده است.
- [ ] فقط پس از تأیید موارد بالا، نسخه در پنل کافه‌بازار بارگذاری و منتشر می‌شود.

**یادآوری:** سبزشدن CI به‌تنهایی اثبات پرداخت واقعی، سلامت کلید امضا، کیفیت مشاوره، سازگاری همه دستگاه‌ها یا آمادگی تجاری نیست.
